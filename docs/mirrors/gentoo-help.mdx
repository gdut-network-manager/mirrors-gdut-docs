# Gentoo 镜像使用帮助

## 简介

Gentoo 是一款基于源代码编译的 Linux 发行版，以其极高的定制性和性能优化能力著称。本镜像提供 Gentoo 官方软件仓库及 distfiles 的镜像服务，可用于 portage 树同步和源代码包下载。

## 镜像信息

- **架构**：AMD 64、ARM 64、x86、ARM
- **版本**：全部
- **更新策略**：每6小时更新一次

## 使用说明

在 `/etc/portage/make.conf` 中加入：

```ini title="/etc/portage/make.conf"
GENTOO_MIRRORS="https://mirrors.gdut.edu.cn/gentoo"
```

然后执行：

```bash
emerge-webrsync
```
