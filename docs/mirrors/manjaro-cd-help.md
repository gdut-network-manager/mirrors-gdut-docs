# Manjaro CD 镜像使用帮助

## 简介

Manjaro CD 是 Manjaro Linux 的安装光盘镜像，包含 XFCE、KDE、GNOME 等多种桌面环境的官方发行版本。本镜像提供 Manjaro 各版本安装光盘的下载服务。

## 镜像信息

- **架构**：全部
- **版本**：全部
- **更新策略**：每6小时更新一次

## 使用说明

请前往[镜像站](https://mirrors.gdut.edu.cn/manjaro-cd/)浏览目录并挑选合适的版本下载。

可根据需要选择不同的桌面环境和架构版本。
