# Arch Linux 镜像使用帮助

## 简介

Arch Linux 是一款基于 x86-64 架构的轻量级、灵活的 Linux 发行版，遵循 KISS 原则。本镜像提供 Arch Linux 官方软件仓库的镜像服务，包含 core、extra、community 等仓库。

## 镜像信息

- **架构**：全部
- **版本**：全部
- **更新策略**：每6小时更新一次

## 使用说明

修改 `/etc/pacman.d/mirrorlist` 在文件的最顶端添加：

<MirrorSources
  type="pacman"
  host="mirrors.gdut.edu.cn"
  path="/archlinux"
  versions={[
    { label: 'Arch Linux', codename: 'arch' },
  ]}
  filePath="/etc/pacman.d/mirrorlist"
  options={{ https: true, source: false, proposed: false, security: false, sudo: true }}
/>

更新软件包缓存：

```bash
sudo pacman -Syy
```
