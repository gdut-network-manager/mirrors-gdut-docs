# CentOS Stream 镜像使用帮助

## 简介

CentOS Stream 是 CentOS 项目在 CentOS 8 之后推出的滚动发布版本，作为 RHEL 的上游开发分支。CentOS Stream 9 起默认使用 dnf 作为包管理工具（替代 yum），仓库结构也发生了较大变化。

:::note[版本说明]

- CentOS 7 已于 2024 年 6 月 30 日结束维护，如需使用请查阅 [CentOS Vault](centos-vault-help)。
- CentOS 8 已于 2021 年 12 月 31 日结束维护。
- 本镜像提供 CentOS Stream 9 和 CentOS Stream 10 的软件仓库。

:::

## 镜像信息

- **架构**：全部
- **版本**：CentOS Stream 9、CentOS Stream 10
- **更新策略**：每6小时更新一次

## 使用说明

CentOS Stream 9 起默认启用了包管理工具 dnf，它是 yum 的替代品。dnf 与 yum 大部分命令通用，同样使用 `/etc/yum.repos.d/` 进行镜像配置。

CentOS Stream 9/10 中源被整合入两个文件：`centos.repo` 和 `centos-addons.repo`。由于官方文件中使用 `metalink` 而非 `baseurl`，需要手动替换。可以通过 Perl 脚本自动替换，或直接覆盖配置文件。

根据你的偏好选择配置方式：

<Tabs groupId="config-method">
  <TabItem value="quick" label="快速配置（Perl 脚本）">

将以下脚本保存为 `update_mirror.pl`：

```bash
cat > update_mirror.pl << 'EOF'
#!/usr/bin/perl

use strict;
use warnings;
use autodie;

my $mirrors = 'https://mirrors.gdut.edu.cn/centos-stream';

if (@ARGV < 1) {
    die "Usage: $0 <filename1> <filename2> ...\n";
}

while (my $filename = shift @ARGV) {
    my $backup_filename = $filename . '.bak';
    rename $filename, $backup_filename;

    open my $input, "<", $backup_filename;
    open my $output, ">", $filename;

    while (<$input>) {
        s/^metalink/# metalink/;

        if (m/^name/) {
            my (undef, $repo, $arch) = split /-/;
            $repo =~ s/^\s+|\s+$//g;
            ($arch = defined $arch ? lc($arch) : '') =~ s/^\s+|\s+$//g;

            if ($repo =~ /^Extras/) {
                $_ .= "baseurl=${mirrors}/SIGs/\$releasever-stream/extras" . ($arch eq 'source' ? "/${arch}/" : "/\$basearch/") . "extras-common\n";
            } else {
                $_ .= "baseurl=${mirrors}/\$releasever-stream/$repo" . ($arch eq 'source' ? "/" : "/\$basearch/") . ($arch ne '' ? "${arch}/tree/" : "os") . "\n";
            }
        }

        print $output $_;
    }
}
EOF
```

然后执行脚本替换 `/etc/yum.repos.d/centos*.repo` 中的源：

```bash
sudo perl update_mirror.pl /etc/yum.repos.d/centos.repo /etc/yum.repos.d/centos-addons.repo
```

如果系统未安装 Perl，可以先安装：

```bash
sudo dnf install perl
```

最后更新软件包缓存：

```bash
sudo dnf clean all && sudo dnf makecache
```

:::tip[提示]

- 如需启用 `enabled=0` 的 repo（如 HighAvailability、RT 等），将其改为 `enabled=1` 即可。
- 截至 2023-05-16，官方源与镜像源中均未发现 nfv-source，建议不要开启 nfv-source。
- `$releasever` 和 `$basearch` 会由 dnf 自动替换为当前系统版本和架构，无需手动修改。

:::
