# FreeBSD 镜像使用帮助

## 简介

FreeBSD 是一款先进的类 UNIX 操作系统，以其稳定性、性能和安全性著称。本镜像提供 FreeBSD 官方发行版仓库的镜像服务，包含 ISO 安装镜像、虚拟机模板及文档资料。

## 镜像信息

- **架构**：AMD 64
- **版本**：最新版本 Release
- **更新策略**：每6小时更新一次

## 使用说明

FreeBSD 发行版仓库。目前 BSD 源只包含官方 ISO 镜像，暂不包含 pkg 和 ports 源。

- ISO 镜像位于 `/releases/ISO-IMAGES`
- 虚拟机模板位于 `/releases/VM-IMAGES`
- 文档及资料位于 `/doc`

FreeBSD 学习：[FreeBSD 简明用户指南](https://bsdelf.github.io/posts/freebsd-brief-user-guide)
