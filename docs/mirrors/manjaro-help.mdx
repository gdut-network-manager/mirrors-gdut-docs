# Manjaro 镜像使用帮助

## 简介

Manjaro 是一款基于 Arch Linux 的用户友好的 Linux 发行版，注重性能与易用性的平衡。本镜像提供 Manjaro 官方软件仓库的镜像服务，包含 stable、testing、unstable 等分支。

## 镜像信息

- **架构**：全部
- **版本**：全部
- **更新策略**：每6小时更新一次

## 使用说明

修改 `/etc/pacman.d/mirrorlist` 在文件的最顶端添加：

<MirrorSources
  type="pacman"
  host="mirrors.gdut.edu.cn"
  path="/manjaro"
  branch="stable"
  versions={[
    { label: 'stable', codename: 'stable' },
    { label: 'testing', codename: 'testing' },
    { label: 'unstable', codename: 'unstable' },
  ]}
  filePath="/etc/pacman.d/mirrorlist"
  options={{ https: true, sudo: true }}
/>

更新软件包缓存：

```bash
sudo pacman -Syy
```
