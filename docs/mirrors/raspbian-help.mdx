# Raspbian 镜像使用帮助

## 简介

Raspbian 是专门用于 ARM 卡片式计算机 Raspberry Pi® "树莓派"的操作系统。

Raspbian 是树莓派的开发与维护机构 The Raspbeery Pi Foundation "树莓派基金会"，推荐用于树莓派的首选系统。

由于以下原因，Raspbian 需要单独组建软件仓库，而不能使用 Debian 的仓库：

- Debian下所有的软件包都需要用 armhf 重新编译。
- 树莓派有部分特有的软件包，例如 BCM2835 CPU 的 GPIO 底层操作库。
- 树莓派用户倾向于探索、尝试最新的软件。这与 Debian 软件源的策略完全不同。

## 镜像信息

- **架构**：全部
- **版本**：全部
- **更新策略**：每6小时更新一次

## 使用说明

推荐同时修改[RaspberryPi源](raspberrypi-help)。

在 Raspbian 12 (bookworm) 之前，Raspbian 的软件源配置文件使用传统的 One-Line-Style，路径为 `/etc/apt/sources.list`；从 Raspbian 13 (trixie) 开始，Raspbian 的软件源配置文件变更为 DEB822 格式，路径为 `/etc/apt/sources.list.d/raspbian.sources`。

可以通过以下命令查看当前系统版本：

```bash
cat /etc/os-release
```

输出示例：

```bash
PRETTY_NAME="Raspbian GNU/Linux 13 (trixie)"
NAME="Raspbian GNU/Linux"
VERSION_ID="13"
VERSION="13 (trixie)"
VERSION_CODENAME=trixie
ID=raspbian
HOME_URL="http://www.raspbian.org/"
SUPPORT_URL="http://www.raspbian.org/RaspbianForums"
BUG_REPORT_URL="http://www.raspbian.org/RaspbianBugs"
```

`VERSION_CODENAME` 后面的是代号。**请在下面的配置中选择与当前系统一致的代号，否则之后的更新操作可能导致系统出现问题。**

### 传统格式（`/etc/apt/sources.list`）

根据对应的 Debian 版本，编辑 `/etc/apt/sources.list` 文件，修改为如下内容。（操作前请做好相应备份）

<MirrorSources
  type="apt-traditional"
  host="mirrors.gdut.edu.cn"
  path="/raspbian/raspbian"
  versions={[
    { label: '13 (trixie)', codename: 'trixie' },
    { label: '12 (bookworm)', codename: 'bookworm' },
  ]}
  components={['main', 'contrib', 'non-free', 'rpi']}
  filePath="/etc/apt/sources.list"
  options={{ https: true, source: true, proposed: false, security: true }}
  securityHost="deb.debian.org"
  securityPath="/debian-security"
/>

:::note[提示]

`rpi` 组件为树莓派相关软件包，`firmware` 组件包含固件（如需可自行添加）。

:::

### DEB822 格式（`/etc/apt/sources.list.d/raspbian.sources`）

<MirrorSources
  type="apt-deb822"
  host="mirrors.gdut.edu.cn"
  path="/raspbian/raspbian"
  versions={[
    { label: '13 (trixie)', codename: 'trixie' },
    { label: '12 (bookworm)', codename: 'bookworm' },
  ]}
  components={['main', 'contrib', 'non-free', 'rpi']}
  filePath="/etc/apt/sources.list.d/raspbian.sources"
  options={{ https: true, source: true, proposed: false, security: true }}
  securityHost="deb.debian.org"
  securityPath="/debian-security"
  signedByKey="/usr/share/keyrings/raspbian-archive-keyring.gpg"
/>

或者直接使用以下命令进行替换：

```bash
# 传统格式
sed -i 's|raspbian.raspberrypi.org|mirrors.gdut.edu.cn|g' /etc/apt/sources.list
# DEB822 格式
sed -i 's|raspbian.raspberrypi.org|mirrors.gdut.edu.cn|g' /etc/apt/sources.list.d/raspbian.sources
```
