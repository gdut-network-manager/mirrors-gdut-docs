# Ubuntu 镜像使用帮助

## 简介

Ubuntu 是基于 Debian 的开源 Linux 发行版，由 Canonical 公司主导开发，广泛应用于桌面、服务器和云环境。本镜像提供 Ubuntu 官方软件仓库的同步。

## 镜像信息

- **架构**：全部
- **版本**：全部
- **更新策略**：每6小时更新一次

## 使用说明

本镜像仅包含 32/64 位 x86 架构处理器的软件包，在 ARM（arm64、armhf）、PowerPC（ppc64el）、RISC-V（riscv64）和 S390x 等架构的设备上（对应官方源为 ports.ubuntu.com）请使用 [Ubuntu Ports 镜像使用帮助](ubuntu-ports-help)。

在 Ubuntu 24.04 之前，Ubuntu 的软件源配置文件使用传统的 One-Line-Style，路径为 `/etc/apt/sources.list`；从 Ubuntu 24.04 开始，Ubuntu 的软件源配置文件变更为 DEB822 格式，路径为 `/etc/apt/sources.list.d/ubuntu.sources`。

可以通过以下命令查看当前系统版本：

```bash
cat /etc/os-release
```

输出示例：

```bash
PRETTY_NAME="Ubuntu 24.04 LTS"
NAME="Ubuntu"
VERSION_ID="24.04"
VERSION="24.04 LTS (Noble Numbat)"
VERSION_CODENAME=noble
ID=ubuntu
ID_LIKE=debian
HOME_URL="https://www.ubuntu.com/"
SUPPORT_URL="https://help.ubuntu.com/"
BUG_REPORT_URL="https://bugs.launchpad.net/ubuntu/"
PRIVACY_POLICY_URL="https://www.ubuntu.com/legal/terms-and-policies/privacy-policy"
UBUNTU_CODENAME=noble
```

`VERSION_ID` 后面的版本号即为当前系统版本，`VERSION_CODENAME` 后面的是代号。代号在软件源配置文件中会被使用。**请在下面的配置中选择符合你的机器的版本号，在替换配置前确认代号一致，否则之后的更新操作可能导致系统出现问题。**

### 传统格式（`/etc/apt/sources.list`）

将系统自带的 `/etc/apt/sources.list` 文件做个备份，然后根据下方配置替换内容即可。

<MirrorSources
  type="apt-traditional"
  host="mirrors.gdut.edu.cn"
  path="/ubuntu"
  versions={[
    { label: '26.04 LTS (resolute)', codename: 'resolute' },
    { label: '24.04 LTS (noble)', codename: 'noble' },
    { label: '22.04 LTS (jammy)', codename: 'jammy' },
  ]}
  components={['main', 'restricted', 'universe', 'multiverse']}
  filePath="/etc/apt/sources.list"
  options={{ https: true, source: true, proposed: true, security: true }}
  securityHost="security.ubuntu.com"
  securityPath="/ubuntu"
/>

### DEB822 格式（`/etc/apt/sources.list.d/ubuntu.sources`）

自 Ubuntu 24.04 起，Ubuntu 开始支持通过 DEB822 格式的配置文件来配置 deb 镜像源。

<MirrorSources
  type="apt-deb822"
  host="mirrors.gdut.edu.cn"
  path="/ubuntu"
  versions={[
    { label: '26.04 LTS (resolute)', codename: 'resolute' },
    { label: '24.04 LTS (noble)', codename: 'noble' },
    { label: '22.04 LTS (jammy)', codename: 'jammy' },
  ]}
  components={['main', 'restricted', 'universe', 'multiverse']}
  filePath="/etc/apt/sources.list.d/ubuntu.sources"
  options={{ https: true, source: true, proposed: true, security: true }}
  securityHost="security.ubuntu.com"
  securityPath="/ubuntu"
  signedByKey="/usr/share/keyrings/ubuntu-archive-keyring.gpg"
/>

:::note[提示]

因镜像站同步有延迟，可能会导致生产环境系统不能及时检查、安装上最新的安全更新，不建议替换 security 源。如有此需求，可关闭上方「本站安全源」开关，安全更新将使用官方源。

:::
