# Maven 镜像使用帮助

## 简介

Maven 是 Java 项目管理和构建工具，用于管理项目的依赖、构建、文档和发布。本镜像提供 Maven 中央仓库的缓存代理服务，加速 Java 依赖包的下载。

## 镜像信息

- **更新策略**：缓存代理，实时回源上游仓库。

## 使用说明

本镜像为缓存代理仓库，不支持仓库搜索功能。

### 在 IntelliJ IDEA 中使用

在用户目录下的 .m2 文件夹中创建一个 `settings.xml` 文件，内容如下

```xml title="~/.m2/settings.xml"
<settings>
    <mirrors>
       <mirror>
            <id>gdutnic</id>
            <name>gdutnic maven</name>
            <url>https://repo.gdut.edu.cn/repository/maven/</url>
            <mirrorOf>*</mirrorOf>
       </mirror>
    </mirrors>
</settings>
```

打开 File - Settings

Build, Execution, Deployment -> Build Tools -> Maven

勾选 User settings file 后面的 Override，并指向前面的 `settings.xml` 文件

![IDEA Maven Settings](pathname:///help/img/maven.png)

### 在 Maven 中使用

以Maven 3.5.2为例：

打开maven配置文件

```bash
vim ./apache-maven-3.5.2/conf/settings.xml
```

找到`<mirrors></mirrors>`标签节点

添加一个的Mirror子节点：

<MirrorSources
  type="maven"
  host="repo.gdut.edu.cn"
  path="/repository/maven"
  versions={[{ label: 'Maven', codename: 'maven' }]}
  options={{ https: true }}
/>

### 在 Maven 项目 POM 中使用

打开项目配置文件 `pom.xml`，在上方配置选项中切换到「POM 配置」选项卡，添加或修改 `<repositories>` 和 `<pluginRepositories>`：

执行maven update更新一下即可。

### 在 Gradle 中使用

在用户目录下创建 Gradle 初始化脚本，会将所有项目中的 Maven 仓库（包括 Maven Central）替换为本站镜像。

<Tabs groupId="gradle-dsl">
  <TabItem value="groovy" label="Groovy DSL" default>

```groovy title="~/.gradle/init.gradle"
allprojects {
    repositories {
        def REPOSITORY_URL = 'https://repo.gdut.edu.cn/repository/maven/'
        all { ArtifactRepository repo ->
            if (repo instanceof MavenArtifactRepository) {
                remove repo
            }
        }
        maven { url REPOSITORY_URL }
    }
}
```

  </TabItem>
  <TabItem value="kotlin" label="Kotlin DSL">

```kotlin title="~/.gradle/init.gradle.kts"
allprojects {
    repositories {
        val REPOSITORY_URL = uri("https://repo.gdut.edu.cn/repository/maven/")
        all {
            if (this is MavenArtifactRepository) {
                remove(this)
            }
        }
        maven { url = REPOSITORY_URL }
    }
}
```

  </TabItem>
</Tabs>

创建脚本后无需额外操作，Gradle 会在每次构建时自动读取并应用。
