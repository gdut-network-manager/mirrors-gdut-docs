# 关于我们

## 简介

[mirrors.gdut.edu.cn](https://mirrors.gdut.edu.cn/) 是广东工业大学学生网管队建立与维护的开源镜像站，致力于为校内用户提供稳定快速的镜像源。

目前我们所提供的镜像服务包括： [Ubuntu](./mirrors/ubuntu-help)， [Debian](./mirrors/debian-help)， [CentOS](./mirrors/centos-help)， [ArchLinux](./mirrors/archlinux-help)， [Manjaro](./mirrors/manjaro-help)， [PyPi](./mirrors/pypi-help) 等等, 具体请参见[镜像站首页](https://mirrors.gdut.edu.cn/)。

如果您有任何建议或疑问，欢迎通过电子邮件联系我们: [stunic@gdut.edu.cn](mailto:stunic@gdut.edu.cn)。

**如果您有对其它发行版或机器架构的软件包有需求，也十分欢迎通过电子邮件联系我们。**

## 常见问题及解答

### 为什么广东工业大学开源镜像没有我用的发行版或者我的机器架构的软件包？

由于服务器磁盘空间有限，我们无法在短期内满足所有用户的需求, 希望用户谅解。当然我们也会根据用户需求热度，在保障服务长期稳定性的前提下逐步提供更全面的镜像资源。

### 为什么我访问不了广东工业大学开源镜像？

广东工业大学开源镜像目前仅限校园网访问，外网是无法访问的。如果您在校内遇到访问问题，可以联系我们进行问题排查。

### 为什么不开放外网访问？

有两方面考虑，一个是安全性，另一个是带宽。即使足够安全了，我们的公网带宽相对于公网的很多镜像站来说并没有优势。所以我们对本镜像站的定位是校园网用户，优势就是内网带宽远远大于公网带宽，在校园网内最高可以提供1Gbps的速度（这取决于您的接入方式，如果是学生宿舍，网速最高可达100Mbps）。

### 我发现广东工业大学开源镜像使用帮助有错误, 该怎么办？

如果发现使用帮助有误，**请您通过电子邮件[联系我们](mailto:stunic@gdut.edu.cn)**，我们将尽快修复，谢谢您的支持和帮助！
