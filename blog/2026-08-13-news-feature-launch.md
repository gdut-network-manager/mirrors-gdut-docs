本站现已上线「新闻公告」板块，用于发布镜像站动态、故障通知、新镜像上线、维护安排等信息。

{/* truncate */}

## 功能说明

- **文档站**（本页面）负责公告内容的发布与管理
- **主站首页**右侧侧边栏新增「最新公告」卡片，实时展示最近 3 条公告标题，点击即可跳转至对应公告详情页
- 支持置顶功能，重要公告可设为 `pin: true` 置顶显示

## 公告分类

| 标签 | 用途 |
| --- | --- |
| 公告 | 通用公告 |
| 故障通知 | 镜像故障、服务异常 |
| 维护通知 | 计划性维护、停机 |
| 新镜像上线 | 新增镜像源 |
| 镜像下线 | 镜像停止维护 |
| 同步异常 | 同步延迟或失败 |
| 功能更新 | 站点功能改进 |

欢迎关注本板块以获取镜像站最新动态。
